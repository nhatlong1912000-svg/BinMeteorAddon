# Bin Meteor

A Minecraft 1.21.11 Fabric addon for Meteor Client.

## Modules
- **ChunkInfo** — reports your current chunk and region coordinates.
- **ChunkFinder** — reserved for loaded-chunk exploration tools.
- **SusChunkFinder** — reserved for configurable suspicious-chunk indicators.
- **StorageESP** — reserved for highlighting visible storage blocks.

## Build
Requires Java 21. Run:

```bash
./gradlew build
```

The addon JAR is created in `build/libs`.
