# Bin Meteor V2 Settings Plan

This branch documents the V2 settings foundation and UI direction.

## Theme
- Red / Black visual identity
- Consistent grouped settings sections
- Clear labels, tooltips, reset defaults, and configuration persistence

## Module settings design
- HUD: position, scale, opacity, color, visibility
- Notifications: sound toggle, message style, duration
- Performance: display refresh throttling and visual update limits
- General: theme, keybind guidance, presets, configuration defaults

## Scope
Settings and cosmetic/performance controls are intended for single-player worlds or environments where the server owner explicitly permits mods. This plan does not include automated base discovery, hidden-player tracking, or tools designed to gain an unfair advantage on multiplayer servers.

## Implementation note
This is a planning document only; it is not a compiled code change or runtime-tested feature.
